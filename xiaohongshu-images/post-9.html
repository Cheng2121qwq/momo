def fibonacci(n):
    """计算斐波那契数列"""
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# 调用示例
print(fibonacci(10)) # 输出：55
你：能解释一下吗？
汪！当然！🐾

这是递归实现：
1. n<=1 时，直接返回 n
2. 否则返回前两个数之和
3. 时间复杂度：O(2^n)
